# FocusCat Lofii Pack Target

This folder is the target runtime pack shape for Lofii. It is incomplete until
Live2D Cubism Editor exports the runtime files.

After export, this folder should contain:

```text
cat.model3.json
<model>.moc3
<texture-folder>/texture_00.png
resources/cover.png
resources/background.png
resources/bongo-parameter-map.json
```

Then copy the folder to:

```text
~/.lofii/bongo/focuscat/
```

Open Lofii, reload Bongo models, and select `focuscat`.
